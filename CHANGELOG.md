# Changelog

[GitHub Releases](https://github.com/jrepp/ipe/releases) is the changelog source for new releases.
GitHub generates release notes from merged pull requests, contributors, and comparison links.

Do not add manual entries to this file.
Describe user-visible changes, compatibility changes, and migration steps in pull requests.
See the [release guide](docs/RELEASES.md) for labels, draft generation, and publication.

The [legacy changelog](docs/CHANGELOG_LEGACY.md) preserves the previous file, including its unreleased notes.
It is an archive, not evidence that those changes shipped in a release.

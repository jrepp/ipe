From input to decision

All stages below are implemented in the v2 runtime; the page calls out what is not characterized or not built.

  1. Inputcaller JSON, schema-validated
  2. Policieslanguage 2; bootstrap sources plus versioned documents
  3. Runtime factspush commits and pull connectors, every fact TTL-bounded
  4. Snapshotone immutable scope snapshot per evaluation
  5. Evaluateinstruction/visit budgets, evidence deadlines
  6. DecisionAllow · Deny · Indeterminate

Removed legacy engine. The in-process parser → bytecode → interpreter stack, the resource index, the lock-free PolicyDataStore, and the Cranelift JIT with adaptive tiering were deleted after the v2 runtime landed. The performance page keeps their archived microbenchmarks for reference only.

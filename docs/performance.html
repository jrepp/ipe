Reproduce this run

make docs-site
make docs-serve
# Open http://127.0.0.1:8000/docs/performance.html

Each workload runs the actual Interpreter::evaluate on hand-built bytecode with 1, 8, or 32 integer comparisons joined by AND. Inputs alternate allow and deny; both outcomes are checked before measurement. Parsing, compilation, context creation, and policy loading are excluded.

After 2,000 warm-up evaluations, 10,000 calls are individually timed with Rust’s monotonic clock. Percentiles use the nearest-rank method and include timer overhead. Throughput is measured separately over 100,000 calls on one unpinned thread. Outliers exceed Q3 + 1.5 × IQR. CPU scheduling, power state, and other programs can affect results; this is not a load test.

The older evaluation Criterion suite contains placeholder paths. This dashboard uses docs_data.rs instead. JIT comparisons remain unmeasured.

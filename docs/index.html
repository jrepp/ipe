IPE is a Rust policy engine. Policies compile to bytecode and evaluate against a Resource–Action–Request context to Allow, Deny, or Error. Your application enforces the decision.

Early-stage. The parser and interpreter work; the compiler is partial and the JIT is experimental. See project status.

A policy says when it applies and what it requires. The intent string stays with the parsed tree.

Lower it to bytecode
A stack interpreter runs the result. Policy snapshots swap atomically, so readers never block.

      
03 · Decide
Return a decision
Allow, Deny, or Error. On the measured interpreter fixtures, p99 is under 1 µs.

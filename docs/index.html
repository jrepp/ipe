IPE is a Rust authorization runtime. Language-2 policy documents and TTL-bounded runtime facts evaluate in scoped tenants to Allow, Deny, or Indeterminate. Your application enforces the decision.

Follow one decision Read the contract

Early-stage. The v2 runtime service ships with typed facts, mandatory TTL, and versioned policy documents; performance under production load is not yet characterized. See project status.

State the intent
A language-2 policy says when it applies and what it requires. Intent strings stay with the parsed rules.

      
02 · Publish
Version it as a document
Publishing appends an immutable revision with typed policy.* parameters and activates it atomically. Facts arrive by push or pull, every value TTL-bounded.

      
03 · Decide
Evaluate a snapshot
Allow, Deny, or Indeterminate. Each evaluation reads one immutable scope snapshot and rechecks evidence deadlines before allowing.

Where authority lives

Inside the guest

  • Pure JavaScript or TypeScript step logic
  • JSON state carried explicitly between fresh contexts
  • Named operation requests and mapped output data
  • No filesystem, network, environment, secrets or Node imports

Inside the trusted host

  • Operator allowlist, parameters, routes and selected fields
  • Credentials, HTTPS I/O, limits and response projection
  • Opaque run-local receipts and sanitized failures
  • Authentication for HTTP, CLI and MCP access

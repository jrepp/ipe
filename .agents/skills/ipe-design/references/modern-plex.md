# Contemporary Plex

The user requested the modernized Plex style from earlier visual studies for the policy overview.
The source study is `design/admin-ux-review/dist/modern.css` in the `ipe-policy-workspace-pr` checkout.
The preview carries its local IBM Plex Sans fonts and license in `tools/product-ship-mocks/fonts/`.

Use IBM Plex Sans, quiet white navigation, pale backgrounds, blue selected states, and layered panels.
Use medium-weight headings, small corner radii, subtle borders, and light shadows.
Keep color accents and small symbols for visual character. Avoid a large sales banner or decorative release stamp.

Put outcome and health summaries before detailed charts. Link each summary to its supporting data or view.
Use consistent time windows for cards and charts. Name units and denominators.
Distinguish a completed evaluation from an allowed release. A denial can be a valid result of a healthy evaluation.
Show unknown evidence separately from evaluation errors. Use exact tables as an alternative to charts.
Label invented history as sample data. Do not turn independent scenario examples into a time series.
A trend can illustrate a hypothesis without proving an actual improvement.

The overview revision applies this direction. Its chart layout awaits user review.

One workflow, several kinds of truth

01 / Source observation

02 / Declared contract

Keep the native conditions

03 / Implementation clues

Look inside the action

Entry points and selected author source reveal input reads, outputs, commands, and API calls. These clues do not prove runtime effects.

04 / Outcome

Leave room for evidence

A workflow definition does not prove a successful run. Run results, environment rules, and external effects require separate observations.

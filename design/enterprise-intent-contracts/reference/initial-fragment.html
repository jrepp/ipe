Both views retain identity, model access, memory, human approval, network restrictions, scoped credentials, external permissions, and audit logs. The token broker issues credentials to the integration gateway. It does not proxy all action traffic. The after view adds a versioned policy model and authorized fact publication. Missing or expired evidence produces an indeterminate result. Enforcement points block that result. These connections describe a conceptual architecture, not a completed implementation.
